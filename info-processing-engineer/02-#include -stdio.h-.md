# #include <stdio.h>

## #include \<stdio.h>

: 데이터의 입/출력을 위해 stdio.h 파일을 현재 파일에 포함

→ 출력 함수(printf()) 사용 가능

1\) #include \[#: 전처리기(먼저 처리하는 기호), include : 포함하다\]

: 외부 파일을 현재 파일에 포함시키기 위해 사용하는 선형처리 지시자

2\) stdio.h : StanDard Input Output (표준 입출력) 헤더 파일

- 헤더 파일(.h) : 자주 사용되는 변수나 함수를 외부에서 편리하게 사용하기  위해 만들어진 파일

3\) main()

: 항상 main()이라는 함수로부터 실행이 된다.

→ 운영체제가 main() 함수를 호출
