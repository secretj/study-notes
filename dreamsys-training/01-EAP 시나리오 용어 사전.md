# EAP 시나리오 용어 사전

> 작성: 2022-03-03 · 태그: 드림시스, EAP, 시나리오 · [노션 원본](https://app.notion.com/p/38d26536726b4c0c975278c66aa74c6c)

- **EAP**

  - **MES** : 생산관리시스템
  - **FDC** :실시간 이상감지
  - **DCP** : 데이터 수집 → 내가 보고싶은 데이터 센서만 보겠다.
  - **MCS** : 물류제어 → OHT
  - **EIS** : 경영관리시스템
  - **EES** : 데이터 수집 /활용
- **OHT** - 카시트/풉(25장 웨이퍼)을 옮김
- CRJOB은 여러개의 PRJOB의 그룹

  - :25장중에 1\~10까지는 1번레시피를 쓰겟다 = PRJOB
- **PPID** : 레시피아이디
- **인터락(interlock)** : 미리 설정해놓은 공정기준을 만족하지 못할 경우, 작동이 중단되어 제품의 품질을 제어해주는 기능

- **<ins>Trigger</ins>** : 조건이 맞을 때 내가 정의한 내용을 자동으로 시행하는 것(조건부라고 할 수 있음)
  - **REMOTE** : 상위시스템이 EAP에 주는것
  - **RECEIVE** : 설비가 EAP에 주는것
  - **SCENE** : 리시브가 실행됐을때 자동으로 실행되는 것

- **<ins>메세지</ins>**
  - **초록색** : EAP →설비
  - **빨간색** : 설비 →EAP
  - **자주 쓰이는 메세지 정리**
    - S3 F17 V1 : 다음 씬 실행
    - S6 : 설비에서 이벤트가 발생했을 때, REPORT 전송 메세지
    - S7 F25 V1 : 특정 PPID(레시피ID)만 받겠다.
    - S2 F33 : REPROT 지정
    - S2 F35 : 2-33에서 지정한 REPORT를 EVENT LINK 시킨다.
    - S2 F37 : LINK된 EVENT를 Enable, Disable 시킨다.

- **<ins>용어 정리</ins>**
  - **PPBodyCheck** : 레시피내용물 체크 (설비가 가지고 있는 레시피와 동일한지)
  - **PRJOB**은 설비가 가지고 있는 것과 EIS로 부터 받은 것이 서로 달라야한다.
  - **ECCHECK** : 설비상태 알려달라
  - **Tracking** : 제품 추적 및 제조 이력 추적 관리
  - **QUEUED** : 대기중
  - **슬랏맵(slotmap)** : 암이 웨이퍼 이상유무를 체크하는것

**MOVE IN** : 시점은 웨이퍼를 **풉에서 빼간 시점** (설비의 입장에서 in)

**MOVE U(OUT)**  : 시점은 웨이퍼를 **풉에 넣은 시점**
