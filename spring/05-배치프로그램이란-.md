# 배치프로그램이란?

: **일괄 처리**(batch processing)란 컴퓨터 프로그램 흐름에 따라 순차적으로 자료를 처리하는 방식을 뜻한다.

개별적으로 어떤 요청이 있을때마다 실시간으로 통신하는 것이 아닌 한꺼번에 일괄적으로 대량 건을 처리하는 것이다. 특히 배치는 보통 정해진 특정한 시간에 실행된다.

### 배치의 특징

1. 대량의 데이터를 처리한다.
2. 특정 시간에 실행한다.
3. 일괄적으로 처리한다.

예시로 변동이 있는 대량의 데이터를 업데이트해야하는데  실시간으로 요청이 어려운(다른 회사의 데이터라 요청을 해야한다던지) 데이터들을 시간을 정해놓고 그 시간에 일괄적으로 업데이트해줄 때 필요하다.

## Spring Batch

### 장점

- 실행 중에 실패하면 실패한 부분부터 다시 실행이 가능하다.
- 이미 실행한 적이 있는 집계 함수를 실행했을 때 이미 실행한 적이 있어 실패하는 기능이 있다.
