# XML 왜 쓰나요?

### XML의 정의

- eXtensible **Markup** Language 의 약자
- **마크업 언어로 만들어**진 응용프로그램 간에 정보를 쉽게 교환하기 위해 만든 데이터 교환 포멧
  *\*마크업 언어는 태그로 만들어진 언어를 뜻함*

- eXensible ? 데이터를 설명하는 태그(tag)를 사용자 마음대로 정의 가능(다른 마크업 언어 생성 가능)

### HTML도 마크업 언어인데?

- XML은 **데이터 전달용**
- HTML은 데이터 표현용
- HTML은 tag가 미리 정의되어 있고 XML은  정의 안되어있음.

## XML의 특징

- HTML과 같이 가장 많이 사용되는 HTTP 프로토콜을 이용해서 전달
- **확장성 있는 태그**를 사용해서 어떤 분야의 데이터도 정확하게 기술가능
- 그렇기 때문에 **태그에 의미 부여가 가능**해서 데이터를 찾기 쉬움
