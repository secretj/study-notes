# Spring Boot에서 Jar와 war

### Spring Boot에서는 많은 설정을 자동으로 해주는데,

그래서 왜 라이브러리를 그냥 Build Gradle에서 컴파일을 알아서 해줄텐데 war와 jar로 구분하는 지 궁금했다.

jar는 java와 관련된 zip파일이고,

war는 웹 어플리케이션과 관련된 zip파일이다.

컴파일은 사람이 짠 코드를 컴퓨터가 알아볼 수 있도록 바꿔주고 jvm으로 읽는 과정이다.
