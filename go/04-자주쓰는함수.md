# 04. PHP에서 쓰던 함수, Go에서는 뭘 쓰지?

**Go 학습 · 04**

PHP는 `explode`, `in_array`, `json_encode` 처럼 함수가 전역에 다 깔려 있어요. Go는 `strings`, `strconv`, `slices` 같은 패키지를 import해서 써요. 매일 쓰던 PHP 함수를 Go로 옮기면 뭐가 되는지 대응표로 정리해요. 표만 보면 금방 잊어버려서, 게시글 검색 요청 하나를 PHP와 Go로 나란히 처리해 보면서 다르게 도는 부분을 짚어요. 예제는 PHP 7.4.33, Go 1.26에서 직접 돌린 결과예요.

| 항목 | 내용 |
|---|---|
| 궁금했던 것 | 자주 쓰는 함수는 Go에서 뭐야? |
| 한 줄 답 | 문자열은 `strings`, 숫자 변환은 `strconv`, 배열은 `slices`·`maps`, JSON은 `encoding/json`, 날짜는 `time` 이에요. `array_map` 같은 건 없어서 for문을 써요. |
| 정리한 날 | 2026-11-04 |
| 같이 볼 글 | Go 학습 내용 · [03. PHP 7.4와 문법 차이](03-php-문법차이.md) |

## 01. 먼저 패키지 지도부터

함수를 외우기 전에 "어느 패키지에 있나"만 알면 나머지는 자동완성이 찾아 줘요.

| 하고 싶은 것 | 패키지 | PHP로 치면 |
|---|---|---|
| 문자열 자르기, 찾기, 바꾸기 | `strings` | `explode`, `strpos`, `str_replace` |
| 문자열 ↔ 숫자 | `strconv` | `intval`, `(string)` |
| 포맷해서 문자열 만들기, 출력 | `fmt` | `sprintf`, `echo`, `var_dump` |
| 목록 다루기 | `slices` (Go 1.21+) | `in_array`, `sort`, `array_unique` |
| 키-값 다루기 | `maps` (Go 1.21+) | `array_keys`, `array_values` |
| JSON | `encoding/json` | `json_encode`, `json_decode` |
| 날짜, 시간 | `time` | `date`, `strtotime`, `time()` |
| 에러 만들고 확인 | `errors`, `fmt.Errorf` | `throw new Exception` |
| 로그 | `log/slog` (Go 1.21+) | `error_log`, Monolog |

## 02. 만들어 볼 것 — 게시글 검색 요청 하나

함수를 표로만 보면 금방 잊어버려요. 그래서 이 글은 작은 일 하나를 정해 두고, 섹션마다 그 일의 한 조각을 PHP와 Go로 나란히 짜 봐요.

정할 일은 **게시글 검색 요청 하나를 처리하는 것**이에요. 사용자가 이런 요청을 보냈다고 해 볼게요.

```
GET /posts?tags=Go, php,,go&limit=20&since=2026-11-04 10:00:00
```

태그에는 대문자, 앞뒤 공백, 빈 값, 중복이 다 섞여 있어요. 실제 요청에서 자주 보는 모양이에요. 이걸 다음 순서로 처리해요.

| 섹션 | 하는 일 | 쓰는 패키지 |
|---|---|---|
| 03 문자열 | `tags` 를 쉼표로 나누고, 공백을 떼고, 소문자로 바꾸고, 빈 값을 버려요 | `strings` |
| 04 숫자 변환 | `limit` 을 숫자로 바꿔요. 이상한 값이 오면 어떻게 되는지 봐요 | `strconv` |
| 05 슬라이스, map | 태그 중복을 지우고, 태그마다 몇 번 나왔는지 세요 | `slices`, map |
| 06 JSON | 응답 JSON을 만들어요 | `encoding/json` |
| 07 날짜 | `since` 를 서울 시간으로 읽어요 | `time` |
| 08 그 밖 | 다음 페이지 링크를 만들어요 | `net/url` |

예제는 HTTP 서버 없이 쿼리 값을 코드에 직접 넣고 결과를 찍어요. 함수가 어떻게 도는지만 보려는 거라서요. 두 파일 다 아래처럼 돌렸어요.

```bash
$ php search.php        # PHP 7.4.33, date.timezone = Asia/Seoul
$ go mod init ex04
$ go run .              # Go 1.26
```

<details>
<summary>PHP 전체 코드 (search.php)</summary>

```php
<?php
// GET /posts?tags=Go, php,,go&limit=20&since=2026-11-04 10:00:00
date_default_timezone_set('Asia/Seoul');
$query = ['tags' => 'Go, php,,go', 'limit' => '20', 'since' => '2026-11-04 10:00:00'];

// 02 문자열: 태그 나누고 다듬기
$tags = [];
foreach (explode(',', $query['tags']) as $t) {
    $t = strtolower(trim($t));
    if ($t !== '') {
        $tags[] = $t;
    }
}
echo "02 tags: "; var_export($tags); echo "\n";

// 03 숫자 변환: limit
foreach (['20', 'abc', '12abc'] as $v) {
    echo "03 intval('$v') = ", intval($v), "\n";
}
$limit = intval($query['limit']);

// 04 배열: 중복 지우고 개수 세기
$unique = array_values(array_unique($tags));
echo "04 unique: ", implode(',', $unique), "\n";
echo "04 count: "; var_export(array_count_values($tags)); echo "\n";

// 05 JSON: 응답 만들기
echo "05 ", json_encode(['tags' => $unique, 'limit' => $limit, 'items' => []]), "\n";

// 06 날짜: since 읽기
$since = strtotime($query['since']);
echo "06 since unix = $since, ", date('Y-m-d H:i', $since), "\n";

// 07 그 밖: 다음 페이지 링크
echo "07 next = /posts?", http_build_query(['tags' => implode(',', $unique), 'page' => 2, 'limit' => $limit]), "\n";
```

</details>

<details>
<summary>Go 전체 코드 (main.go)</summary>

```go
package main

import (
    "encoding/json"
    "fmt"
    "net/url"
    "slices"
    "strconv"
    "strings"
    "time"
)

type SearchResp struct {
    Tags  []string `json:"tags"`
    Limit int      `json:"limit"`
    Items []string `json:"items"`
}

func main() {
    // GET /posts?tags=Go, php,,go&limit=20&since=2026-11-04 10:00:00
    query := url.Values{}
    query.Set("tags", "Go, php,,go")
    query.Set("limit", "20")
    query.Set("since", "2026-11-04 10:00:00")

    // 02 문자열: 태그 나누고 다듬기
    var tags []string
    for _, t := range strings.Split(query.Get("tags"), ",") {
        t = strings.ToLower(strings.TrimSpace(t))
        if t != "" {
            tags = append(tags, t)
        }
    }
    fmt.Printf("02 tags: %q\n", tags)

    // 03 숫자 변환: limit
    for _, v := range []string{"20", "abc", "12abc"} {
        n, err := strconv.Atoi(v)
        fmt.Printf("03 Atoi(%q) = %d, err = %v\n", v, n, err)
    }
    limit, err := strconv.Atoi(query.Get("limit"))
    if err != nil {
        fmt.Println("400 limit은 숫자여야 해요")
        return
    }

    // 04 슬라이스, map: 중복 지우고 개수 세기
    unique := slices.Clone(tags)
    slices.Sort(unique)
    unique = slices.Compact(unique)
    fmt.Printf("04 unique: %q\n", unique)
    count := map[string]int{}
    for _, t := range tags {
        count[t]++
    }
    fmt.Println("04 count:", count)

    // 05 JSON: 응답 만들기
    var items []string // 검색 결과가 없어서 nil
    b, _ := json.Marshal(SearchResp{Tags: unique, Limit: limit, Items: items})
    fmt.Println("05", string(b))
    b, _ = json.Marshal(SearchResp{Tags: unique, Limit: limit, Items: []string{}})
    fmt.Println("05", string(b))

    // 06 날짜: since 읽기
    t1, _ := time.Parse(time.DateTime, query.Get("since"))
    seoul, _ := time.LoadLocation("Asia/Seoul")
    t2, _ := time.ParseInLocation(time.DateTime, query.Get("since"), seoul)
    fmt.Println("06 Parse           unix =", t1.Unix(), t1.Format("2006-01-02 15:04 MST"))
    fmt.Println("06 ParseInLocation unix =", t2.Unix(), t2.Format("2006-01-02 15:04 MST"))

    // 07 그 밖: 다음 페이지 링크
    next := url.Values{}
    next.Set("tags", strings.Join(unique, ","))
    next.Set("page", "2")
    next.Set("limit", strconv.Itoa(limit))
    fmt.Println("07 next = /posts?" + next.Encode())
}
```

</details>

## 03. 문자열 — `strings`

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `strlen($s)` | `len(s)` | 둘 다 바이트 수예요 |
| `mb_strlen($s)` | `utf8.RuneCountInString(s)` | 글자 수 |
| `explode(',', $s)` | `strings.Split(s, ",")` | 인자 순서가 반대예요 |
| `implode(',', $arr)` | `strings.Join(arr, ",")` | 여기도 반대 |
| `strpos($s, 'a') !== false` | `strings.Contains(s, "a")` | 7.4엔 `str_contains` 가 없죠 |
| `strpos($s, 'a')` | `strings.Index(s, "a")` | 없으면 `false` 대신 `-1` |
| `substr($s, 0, 3) === 'abc'` | `strings.HasPrefix(s, "abc")` | 끝은 `HasSuffix` |
| `str_replace('a', 'b', $s)` | `strings.ReplaceAll(s, "a", "b")` | `Replace(s, a, b, n)` 는 n개만 |
| `trim($s)` | `strings.TrimSpace(s)` |  |
| `strtolower` / `strtoupper` | `strings.ToLower` / `ToUpper` |  |
| `strcasecmp($a, $b) === 0` | `strings.EqualFold(a, b)` | 대소문자 무시 비교 |
| `str_repeat` | `strings.Repeat` |  |
| `substr_count` | `strings.Count` |  |
| `list($k, $v) = explode('=', $s, 2)` | `k, v, ok := strings.Cut(s, "=")` | 찾았는지(`ok`)까지 줘요 |
| `preg_split('/\s+/', trim($s))` | `strings.Fields(s)` | 공백 여러 개를 알아서 처리 |
| `sprintf('%05d', $n)` | `fmt.Sprintf("%05d", n)` | 거의 같아요 |
| `$s .= 'x'` (반복문 안) | `strings.Builder` | `b.WriteString("x")` 후 `b.String()` |
| `preg_match`, `preg_replace` | `regexp.MustCompile(...)` 후 `MatchString`, `ReplaceAllString` | 아래 주의 참고 |

### 예제로 보기

먼저 `tags=Go, php,,go` 를 깨끗한 목록으로 만들어요. PHP에서는 보통 `explode` 로 나누고 `trim`, `strtolower` 를 거쳐 빈 값을 빼죠.

```php
$tags = [];
foreach (explode(',', $query['tags']) as $t) {
    $t = strtolower(trim($t));
    if ($t !== '') {
        $tags[] = $t;
    }
}
```

Go로 옮기면 이렇게 돼요.

```go
var tags []string
for _, t := range strings.Split(query.Get("tags"), ",") {
    t = strings.ToLower(strings.TrimSpace(t))
    if t != "" {
        tags = append(tags, t)
    }
}
```

두 쪽 다 돌려 보면 결과가 같아요.

```
PHP  02 tags: array ( 0 => 'go', 1 => 'php', 2 => 'go', )
Go   02 tags: ["go" "php" "go"]
```

함수 이름만 바뀌고 흐름은 그대로예요. 눈여겨볼 건 두 가지예요. `strings.Split` 은 PHP `explode` 와 인자 순서가 반대예요(문자열이 먼저). 그리고 `$tags[] = $t` 자리가 `tags = append(tags, t)` 로 바뀌었어요. `append` 는 결과를 꼭 다시 대입해야 해요. 중복 `go` 는 아직 남아 있어요. 05에서 지워요.

### 이름은 같은데 다르게 도는 것

- **`strings.Trim(s, "ab")` 는 "ab"를 떼는 게 아니에요.** PHP `trim($s, "ab")` 처럼 a나 b에 해당하는 글자를 양 끝에서 다 떼요. `Trim("abcba", "ab")` 는 `"c"` 예요. 앞에 붙은 문자열 하나만 떼려면 `TrimPrefix` 를 써요.
- **정규식에 앞뒤 살피기(lookahead)가 없어요.** Go 정규식(RE2)은 `(?=...)`, `(?!...)`, 역참조 `\1` 을 지원하지 않아요. PHP preg 패턴을 그대로 옮기면 `invalid or unsupported Perl syntax` 에러가 나요. 대신 아무리 긴 입력에도 느려지지 않아요.
- **`s[0:3]` 은 바이트로 잘라요.** `substr` 처럼 한글이 깨질 수 있어요. 글자 단위로 자르려면 `[]rune(s)` 로 바꿔서 잘라요.

## 04. 숫자 변환 — `strconv`

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `intval($s)`, `(int)$s` | `n, err := strconv.Atoi(s)` | 실패하면 에러를 줘요 |
| `(string)$n` | `strconv.Itoa(n)` | `string(n)` 은 쓰면 안 돼요 (아래) |
| `(int)` 큰 숫자 (int64) | `strconv.ParseInt(s, 10, 64)` | DB ID는 보통 int64 |
| `floatval($s)` | `strconv.ParseFloat(s, 64)` |  |
| `is_numeric($s)` | `_, err := strconv.Atoi(s); err == nil` | 따로 함수가 없어요 |
| `max($a, $b)`, `min` | `max(a, b)`, `min` | Go 1.21부터 내장 함수 |

### 예제로 보기

이제 `limit` 을 숫자로 바꿔요. 정상 값 `"20"` 말고도 사용자가 `"abc"`, `"12abc"` 를 보냈을 때를 같이 돌려 봤어요.

```
foreach (['20', 'abc', '12abc'] as $v) {
    echo "03 intval('$v') = ", intval($v), "\n";
}
```

Go로 옮기면 이렇게 돼요.

```go
for _, v := range []string{"20", "abc", "12abc"} {
    n, err := strconv.Atoi(v)
    fmt.Printf("03 Atoi(%q) = %d, err = %v\n", v, n, err)
}
```

결과를 나란히 놓으면 차이가 바로 보여요.

```
PHP  03 intval('20') = 20
PHP  03 intval('abc') = 0
PHP  03 intval('12abc') = 12                 ← 앞의 숫자만 읽고 넘어가요
Go   03 Atoi("20") = 20, err = <nil>
Go   03 Atoi("abc") = 0, err = strconv.Atoi: parsing "abc": invalid syntax
Go   03 Atoi("12abc") = 0, err = strconv.Atoi: parsing "12abc": invalid syntax   ← 에러예요
```

PHP는 이상한 값도 조용히 숫자로 바꿔 줘요. Go는 숫자가 아니면 에러를 돌려줘요. 그래서 Go 코드에는 이 에러를 받아서 400으로 돌려주는 줄이 꼭 붙어요.

```go
limit, err := strconv.Atoi(query.Get("limit"))
if err != nil {
    fmt.Println("400 limit은 숫자여야 해요")
    return
}
```

- **PHP `intval("12abc")` 는 12, Go `Atoi("12abc")` 는 에러예요.** 쿼리 파라미터에 이상한 값이 오면 PHP는 조용히 넘어가고 Go는 에러가 나요. 그래서 Go에서는 이 에러를 400으로 돌려주는 코드가 꼭 들어가요.
- **`string(65)` 는 `"65"` 가 아니라 `"A"` 예요.** 숫자를 문자 코드로 봐요. `go vet` 이 경고해 줘요. 숫자를 글자로 바꿀 땐 늘 `strconv.Itoa` 예요.

## 05. 배열 → 슬라이스는 `slices`, map은 `maps`

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `count($arr)` | `len(s)` | map도 `len(m)` |
| `empty($arr)` | `len(s) == 0` | nil이어도 0이라 안전해요 |
| `$arr[] = $x`, `array_push` | `s = append(s, x)` | 꼭 다시 대입해요 |
| `array_merge($a, $b)` | `append(a, b...)`, `slices.Concat(a, b)` |  |
| `in_array($x, $arr, true)` | `slices.Contains(s, x)` |  |
| `array_search($x, $arr)` | `slices.Index(s, x)` | 없으면 `-1` |
| `sort($arr)` | `slices.Sort(s)` | 원본을 정렬해요 |
| `usort($arr, fn($a, $b) => ...)` | `slices.SortFunc(s, func(a, b T) int {...})` | 비교 결과는 음수/0/양수 |
| `array_unique($arr)` | `slices.Sort(s)` 후 `slices.Compact(s)` | 붙어 있는 중복만 지워요 |
| `array_reverse` | `slices.Reverse(s)` | 원본을 뒤집어요 |
| `array_slice($arr, 1, 2)` | `s[1:3]` | 원본 배열을 같이 봐요 ([03편](03-php-문법차이.md)) |
| `array_filter` | for문, 또는 `slices.DeleteFunc` | DeleteFunc는 "지울 것"을 골라요 |
| `array_map` | for문 | 표준 라이브러리에 없어요 |
| `isset($m['k'])` | `v, ok := m["k"]` |  |
| `unset($m['k'])` | `delete(m, "k")` |  |
| `array_keys($m)` | `slices.Collect(maps.Keys(m))` | 순서는 랜덤, 정렬하려면 `slices.Sorted` |

### 예제로 보기

03에서 만든 `["go" "php" "go"]` 에서 중복을 지우고, 태그마다 몇 번 나왔는지 세요. PHP에는 `array_unique` 와 `array_count_values` 가 있죠.

```php
$unique = array_values(array_unique($tags));
echo "04 unique: ", implode(',', $unique), "\n";
echo "04 count: "; var_export(array_count_values($tags));
```

Go로 옮기면 이렇게 돼요.

```go
unique := slices.Clone(tags)     // 원본 tags는 그대로 두려고 복사해요
slices.Sort(unique)
unique = slices.Compact(unique)  // 붙어 있는 같은 값만 하나로 합쳐요
fmt.Printf("04 unique: %q\n", unique)

count := map[string]int{}        // array_count_values 대신 map으로 직접 세요
for _, t := range tags {
    count[t]++                   // 없는 키는 0에서 시작해요
}
fmt.Println("04 count:", count)
```

결과는 이렇게 나왔어요.

```
PHP  04 unique: go,php
PHP  04 count: array ( 'go' => 2, 'php' => 1, )
Go   04 unique: ["go" "php"]
Go   04 count: map[go:2 php:1]
```

결과는 같은데 Go 쪽에 `Sort` 가 끼어 있죠. `slices.Compact` 는 **바로 옆에 붙은** 같은 값만 합쳐요. 정렬 없이 돌리면 중복이 그대로 남아요.

```
Compact만: ["go" "php" "go"]     ← 떨어져 있는 go는 못 지워요
```

정렬하면 순서가 바뀌어요. PHP `array_unique` 처럼 처음 나온 순서를 지키고 싶으면, 본 적 있는 값을 map에 적어 두면서 걸러요.

```go
seen := map[string]bool{}
var keep []string
for _, t := range tags {
    if !seen[t] {
        seen[t] = true
        keep = append(keep, t)
    }
}
// 결과: 순서 유지: ["go" "php"]
```

하나 더 있어요. map을 `for range` 로 돌면 **돌릴 때마다 순서가 달라요.** 같은 map을 세 번 돌려 봤어요.

```
go php java
php java go     ← 두 번째만 순서가 달라요
go php java
```

PHP 연관 배열은 넣은 순서를 지켜 주니까 이 차이에서 자주 걸려요. 위 결과의 `map[go:2 php:1]` 은 `fmt` 가 찍을 때만 키를 정렬해 준 거예요. 순서가 필요하면 키를 정렬해서 돌아요(아래 `maps.Keys` 이야기).

`array_map` 이 없어서 처음엔 답답한데, Go에서는 for문이 제일 읽기 쉽다고 보는 문화예요. 팀에서 공통 함수로 만들기보다 그냥 for문을 쓰는 게 보통이에요.

```go
// PHP: $ids = array_map(fn($u) => $u->id, $users);
ids := make([]int64, 0, len(users))   // 크기를 미리 잡아 두면 append가 빨라요
for _, u := range users {
    ids = append(ids, u.ID)
}
```

`maps.Keys` 는 Go 1.23부터 슬라이스가 아니라 이터레이터(`iter.Seq`)를 돌려줘요. 그래서 슬라이스가 필요하면 `slices.Collect` 나 `slices.Sorted` 로 한 번 감싸야 해요. 옛날 블로그 글의 `maps.Keys` 예제가 컴파일이 안 되면 이 때문이에요.

## 06. JSON — `encoding/json`

Go는 응답 모양을 struct로 먼저 정하고, 필드 옆에 JSON 키 이름을 태그로 달아요. 사용자 하나를 JSON으로 만들고, 다시 읽어 오는 코드예요.

```go
type User struct {
    ID    int64  `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email,omitempty"` // 비어 있으면 필드를 빼요
    pass  string // 소문자 필드는 JSON에 안 나가요
}

u := User{ID: 1, Name: "진형", pass: "secret"}
b, _ := json.Marshal(u) // json_encode($u)
fmt.Println(string(b))

var got User
err := json.Unmarshal([]byte(`{"id":2,"name":"민수","email":"a@b.c"}`), &got) // json_decode($body)
fmt.Printf("%+v %v\n", got, err)
```

돌리면 이렇게 나와요.

```
{"id":1,"name":"진형"}                       ← email은 비어서 빠지고, pass는 소문자라 안 나가요
{ID:2 Name:민수 Email:a@b.c pass:} <nil>
```

- **struct에 담는 게 기본이에요.** 필드 옆의 `` `json:"..."` `` (태그)로 JSON 키 이름을 정해요. PHP처럼 연관 배열로 받고 싶으면 `map[string]any` 에 담을 수는 있지만, 꺼낼 때마다 타입을 확인해야 해서 잘 안 써요.
- **`map[string]any` 로 받으면 숫자는 다 `float64` 예요.** `{"n":1}` 의 1이 int가 아니라 float64로 들어와요. 큰 ID는 정밀도가 깨질 수 있어요.
- **소문자 필드는 JSON에 안 나가요.** 03편의 "소문자 = 밖에서 못 봄" 규칙이 json 패키지에도 적용돼요. 응답에 필드가 안 나오면 대소문자부터 봐요.
- **빈 슬라이스는 `[]`, nil 슬라이스는 `null` 이에요.** 아래 예제에서 직접 봐요.

### 예제로 보기

이제 검색 결과를 응답으로 만들어요. 검색 결과가 하나도 없을 때를 봐요. PHP에서는 빈 배열을 넣고 `json_encode` 하면 끝이죠.

```
echo json_encode(['tags' => $unique, 'limit' => $limit, 'items' => []]);
```

Go로 옮기면 이렇게 돼요.

```go
type SearchResp struct {
    Tags  []string `json:"tags"`
    Limit int      `json:"limit"`
    Items []string `json:"items"`
}

var items []string // 검색 결과가 없어서 nil
b, _ := json.Marshal(SearchResp{Tags: unique, Limit: limit, Items: items})
fmt.Println("05", string(b))
b, _ = json.Marshal(SearchResp{Tags: unique, Limit: limit, Items: []string{}})
fmt.Println("05", string(b))
```

Go에서는 `items` 를 두 가지로 넣어 봤어요. 아무것도 안 넣은 슬라이스(`nil`)와 빈 슬라이스예요.

```
PHP  05 {"tags":["go","php"],"limit":20,"items":[]}
Go   05 {"tags":["go","php"],"limit":20,"items":null}   ← nil 슬라이스
Go   05 {"tags":["go","php"],"limit":20,"items":[]}     ← []string{}
```

`var items []string` 로만 선언하고 아무것도 안 넣으면 `null` 이 나가요. 프론트에서 `items.length` 를 읽다가 에러가 나는 흔한 원인이에요. 목록 필드는 `[]string{}` 이나 `make([]string, 0)` 으로 만들어서 넘겨요.

## 07. 날짜와 시간 — `time`

Go 날짜 포맷이 제일 낯설어요. `Y-m-d` 같은 기호 대신 **정해진 날짜 하나를 원하는 모양으로 써요.** 그 날짜가 2006년 1월 2일 15시 04분 05초예요. "1월 2일 3시 4분 5초 06년"으로 1, 2, 3, 4, 5, 6 순서라고 외우면 쉬워요.

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `time()` | `time.Now().Unix()` |  |
| `date('Y-m-d H:i:s')` | `time.Now().Format("2006-01-02 15:04:05")` | 상수 `time.DateTime` 도 있어요 |
| `date('Y-m-d')` | `t.Format(time.DateOnly)` |  |
| `strtotime('2026-11-04 10:00:00')` | `time.ParseInLocation(time.DateTime, s, loc)` | 아래 주의 참고 |
| `strtotime('+1 day')` | `t.AddDate(0, 0, 1)` | 시간 단위는 `t.Add(2 * time.Hour)` |
| `sleep(1)` | `time.Sleep(time.Second)` | `time.Sleep(1)` 은 1나노초예요 |
| `microtime(true)` 로 걸린 시간 | `start := time.Now()` … `time.Since(start)` |  |
| `date_default_timezone_set` | `time.LoadLocation("Asia/Seoul")` | 전역 설정이 아니라 값마다 붙어요 |

### 예제로 보기

`since=2026-11-04 10:00:00` 은 서울 시간으로 보낸 값이에요. PHP는 `date.timezone` 을 서울로 해 두고 `strtotime` 으로 읽었죠.

```php
date_default_timezone_set('Asia/Seoul');
$since = strtotime($query['since']);
echo "06 since unix = $since, ", date('Y-m-d H:i', $since), "\n";
```

Go로 옮기면 이렇게 돼요.

```go
t1, _ := time.Parse(time.DateTime, query.Get("since"))
seoul, _ := time.LoadLocation("Asia/Seoul")
t2, _ := time.ParseInLocation(time.DateTime, query.Get("since"), seoul)
fmt.Println("06 Parse           unix =", t1.Unix(), t1.Format("2006-01-02 15:04 MST"))
fmt.Println("06 ParseInLocation unix =", t2.Unix(), t2.Format("2006-01-02 15:04 MST"))
```

Go는 두 함수로 읽어서 Unix 시각을 비교해 봤어요. `time.DateTime` 은 `"2006-01-02 15:04:05"` 레이아웃 상수예요.

```
PHP  06 since unix = 1793754000, 2026-11-04 10:00
Go   06 Parse           unix = 1793786400 2026-11-04 10:00 UTC   ← 32400초(9시간) 늦어요
Go   06 ParseInLocation unix = 1793754000 2026-11-04 10:00 KST   ← PHP와 같아요
```

찍힌 시각은 둘 다 10:00 인데 Unix 값이 달라요. `time.Parse` 는 문자열에 시간대가 없으면 UTC 10시로 읽어서 서울 기준으로는 9시간 뒤가 돼요. 에러도 안 나서 그대로 쿼리에 들어가면 9시간 어긋난 목록이 나와요.

- **`time.Parse` 는 시간대가 없으면 UTC로 읽어요.** PHP는 `date.timezone` 설정을 따라가지만, Go는 문자열에 시간대가 없으면 UTC예요. 사용자 시간대로 읽으려면 `ParseInLocation` 에 그 사용자의 시간대를 넘겨요. 해외에서 접속하는 서비스라면 서버 시간대를 고정하지 말고, 요청에서 받은 시간대를 써요.
- **`01` 이랑 `02` 를 헷갈리면 조용히 틀려요.** `"2006-01-01"` 로 쓰면 일 자리에 월이 들어가요. 에러가 안 나서 더 위험해요.

## 08. 그 밖에 자주 쓰는 것

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `echo`, `print_r` | `fmt.Println`, `fmt.Printf("%+v", x)` | `%+v` 는 필드 이름까지 찍어요 |
| `var_dump($x)` | `fmt.Printf("%#v", x)` | 타입까지 찍어요 |
| `error_log` | `slog.Error("msg", "key", v)` | 키-값 로그 |
| `throw new Exception('x')` | `return errors.New("x")` | 포맷이 필요하면 `fmt.Errorf` |
| `exit(1)`, `die()` | `os.Exit(1)` | `defer` 가 안 돌아요 |
| `file_get_contents($path)` | `os.ReadFile(path)` | `[]byte` 로 줘요 |
| `file_put_contents` | `os.WriteFile(path, b, 0o644)` | 권한을 꼭 넘겨요 |
| `http_build_query($arr)` | `url.Values{...}.Encode()` | 키가 알파벳 순으로 정렬돼요 |
| `urlencode` / `rawurlencode` | `url.QueryEscape` / `url.PathEscape` | 공백이 `+` / `%20` |
| `htmlspecialchars` | `html.EscapeString` | HTML 만들 땐 `html/template` 이 알아서 해요 |
| `base64_encode` | `base64.StdEncoding.EncodeToString(b)` |  |
| `md5($s)` | `md5.Sum(b)` 후 `hex.EncodeToString(sum[:])` | 두 단계예요 |
| `password_hash` | `bcrypt.GenerateFromPassword` | `golang.org/x/crypto/bcrypt` |
| `uniqid()` | `uuid.NewString()` | `github.com/google/uuid` |

### 예제로 보기

마지막으로 응답에 넣을 다음 페이지 링크를 만들어요. PHP에서는 `http_build_query` 에 배열을 넘기죠.

```
echo "07 next = /posts?", http_build_query(['tags' => implode(',', $unique), 'page' => 2, 'limit' => $limit]);
```

Go로 옮기면 이렇게 돼요.

```go
next := url.Values{}
next.Set("tags", strings.Join(unique, ","))
next.Set("page", "2")
next.Set("limit", strconv.Itoa(limit))   // 값은 문자열이라 Itoa로 바꿔요
fmt.Println("07 next = /posts?" + next.Encode())
```

결과를 비교해 봐요.

```
PHP  07 next = /posts?tags=go%2Cphp&page=2&limit=20
Go   07 next = /posts?limit=20&page=2&tags=go%2Cphp   ← 키가 알파벳 순이에요
```

쉼표가 `%2C` 로 바뀌는 것까지 같아요. 다른 건 키 순서예요. `url.Values` 는 map이라서 `Encode` 할 때 키를 정렬해요. 링크로 쓰기엔 문제가 없어요. 다만 API 서명처럼 문자열이 글자 하나까지 같아야 하는 곳에서는 PHP와 결과가 달라지니 조심해요.

## 09. 스스로 확인해 보기

#### 1. PHP에서 `$limit = intval($_GET['limit'] ?? 50);` 이던 코드를 Go로 옮겼어요. 사용자가 `?limit=abc` 를 보내면 PHP와 Go는 각각 어떻게 될까?

<details>
<summary>답 보기</summary>

PHP는 `intval("abc")` 가 0이라서 limit 0으로 조용히 조회돼요. 빈 목록이 나가고 아무도 몰라요. Go는 `strconv.Atoi("abc")` 가 에러를 주니까 그 에러를 400으로 돌려주면 돼요. gin이면 `ShouldBindQuery` 가 같은 일을 해 줘요.

</details>

#### 2. DB에는 KST로 `"2026-11-04 10:00:00"` 이 저장돼 있어요. `time.Parse(time.DateTime, s)` 로 읽어서 `.Unix()` 를 찍으면 PHP `strtotime` (timezone=Asia/Seoul) 결과랑 같을까?

<details>
<summary>답 보기</summary>

9시간(32400초) 차이가 나요. Go `time.Parse` 는 시간대가 없는 문자열을 UTC로 읽거든요. `time.ParseInLocation` 에 저장할 때 쓴 시간대를 넘겨야 같아져요.

</details>
