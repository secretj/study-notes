# 04. PHP에서 쓰던 함수, Go에서는 뭘 쓰지?

**Go 학습 · 04**

PHP는 `explode`, `in_array`, `json_encode` 처럼 함수가 전역에 다 깔려 있어요. Go는 `strings`, `strconv`, `slices` 같은 패키지를 import해서 써요. 매일 쓰던 PHP 함수를 Go로 옮기면 뭐가 되는지 대응표로 정리하고, 이름은 비슷한데 다르게 도는 것만 따로 짚어요.

| 항목 | 내용 |
|---|---|
| 궁금했던 것 | 자주 쓰는 함수는 Go에서 뭐야? |
| 한 줄 답 | 문자열은 `strings`, 숫자 변환은 `strconv`, 배열은 `slices`·`maps`, JSON은 `encoding/json`, 날짜는 `time` 이에요. `array_map` 같은 건 없어서 for문을 써요. |
| 정리한 날 | 2026-11-04 |
| 같이 볼 글 | [Go 학습 내용](https://wiki.mailplug.co.kr/confluence/pages/viewpage.action?pageId=224339879) · [03. PHP 7.4와 문법 차이](https://wiki.mailplug.co.kr/confluence/pages/viewpage.action?pageId=224340554) |

## 01. 먼저 패키지 지도부터

함수를 외우기 전에 "어느 패키지에 있나"만 알면 나머지는 자동완성이 찾아 줘요.

| 하고 싶은 것 | 패키지 | PHP로 치면 |
|---|---|---|
| 문자열 자르기, 찾기, 바꾸기 | `strings` | `explode`, `strpos`, `str_replace` |
| 문자열 ↔ 숫자 | `strconv` | `intval`, `(string)` |
| 포맷해서 문자열 만들기, 출력 | `fmt` | `sprintf`, `echo`, `var_dump` |
| 목록 다루기 | `slices` (Go 1.21+) | `in_array`, `sort`, `array_unique` |
| 키-값 다루기 | `maps` (Go 1.21+) | `array_keys`, `array_values` |
| JSON | `encoding/json` | `json_encode`, `json_decode` |
| 날짜, 시간 | `time` | `date`, `strtotime`, `time()` |
| 에러 만들고 확인 | `errors`, `fmt.Errorf` | `throw new Exception` |
| 로그 | `log/slog` (Go 1.21+) | `error_log`, Monolog |

## 02. 문자열 — `strings`

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `strlen($s)` | `len(s)` | 둘 다 바이트 수예요 |
| `mb_strlen($s)` | `utf8.RuneCountInString(s)` | 글자 수 |
| `explode(',', $s)` | `strings.Split(s, ",")` | 인자 순서가 반대예요 |
| `implode(',', $arr)` | `strings.Join(arr, ",")` | 여기도 반대 |
| `strpos($s, 'a') !== false` | `strings.Contains(s, "a")` | 7.4엔 `str_contains` 가 없죠 |
| `strpos($s, 'a')` | `strings.Index(s, "a")` | 없으면 `false` 대신 `-1` |
| `substr($s, 0, 3) === 'abc'` | `strings.HasPrefix(s, "abc")` | 끝은 `HasSuffix` |
| `str_replace('a', 'b', $s)` | `strings.ReplaceAll(s, "a", "b")` | `Replace(s, a, b, n)` 는 n개만 |
| `trim($s)` | `strings.TrimSpace(s)` |  |
| `strtolower` / `strtoupper` | `strings.ToLower` / `ToUpper` |  |
| `strcasecmp($a, $b) === 0` | `strings.EqualFold(a, b)` | 대소문자 무시 비교 |
| `str_repeat` | `strings.Repeat` |  |
| `substr_count` | `strings.Count` |  |
| `list($k, $v) = explode('=', $s, 2)` | `k, v, ok := strings.Cut(s, "=")` | 찾았는지(`ok`)까지 줘요 |
| `preg_split('/\s+/', trim($s))` | `strings.Fields(s)` | 공백 여러 개를 알아서 처리 |
| `sprintf('%05d', $n)` | `fmt.Sprintf("%05d", n)` | 거의 같아요 |
| `$s .= 'x'` (반복문 안) | `strings.Builder` | `b.WriteString("x")` 후 `b.String()` |
| `preg_match`, `preg_replace` | `regexp.MustCompile(...)` 후 `MatchString`, `ReplaceAllString` | 아래 주의 참고 |

### 이름은 같은데 다르게 도는 것

- **`strings.Trim(s, "ab")` 는 "ab"를 떼는 게 아니에요.** PHP `trim($s, "ab")` 처럼 a나 b에 해당하는 글자를 양 끝에서 다 떼요. `Trim("abcba", "ab")` 는 `"c"` 예요. 앞에 붙은 문자열 하나만 떼려면 `TrimPrefix` 를 써요.
- **정규식에 앞뒤 살피기(lookahead)가 없어요.** Go 정규식(RE2)은 `(?=...)`, `(?!...)`, 역참조 `\1` 을 지원하지 않아요. PHP preg 패턴을 그대로 옮기면 `invalid or unsupported Perl syntax` 에러가 나요. 대신 아무리 긴 입력에도 느려지지 않아요.
- **`s[0:3]` 은 바이트로 잘라요.** `substr` 처럼 한글이 깨질 수 있어요. 글자 단위로 자르려면 `[]rune(s)` 로 바꿔서 잘라요.

## 03. 숫자 변환 — `strconv`

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `intval($s)`, `(int)$s` | `n, err := strconv.Atoi(s)` | 실패하면 에러를 줘요 |
| `(string)$n` | `strconv.Itoa(n)` | `string(n)` 은 쓰면 안 돼요 (아래) |
| `(int)` 큰 숫자 (int64) | `strconv.ParseInt(s, 10, 64)` | DB ID는 보통 int64 |
| `floatval($s)` | `strconv.ParseFloat(s, 64)` |  |
| `is_numeric($s)` | `_, err := strconv.Atoi(s); err == nil` | 따로 함수가 없어요 |
| `max($a, $b)`, `min` | `max(a, b)`, `min` | Go 1.21부터 내장 함수 |

- **PHP `intval("12abc")` 는 12, Go `Atoi("12abc")` 는 에러예요.** 쿼리 파라미터에 이상한 값이 오면 PHP는 조용히 넘어가고 Go는 에러가 나요. 그래서 Go에서는 이 에러를 400으로 돌려주는 코드가 꼭 들어가요.
- **`string(65)` 는 `"65"` 가 아니라 `"A"` 예요.** 숫자를 문자 코드로 봐요. `go vet` 이 경고해 줘요. 숫자를 글자로 바꿀 땐 늘 `strconv.Itoa` 예요.

## 04. 배열 → 슬라이스는 `slices`, map은 `maps`

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `count($arr)` | `len(s)` | map도 `len(m)` |
| `empty($arr)` | `len(s) == 0` | nil이어도 0이라 안전해요 |
| `$arr[] = $x`, `array_push` | `s = append(s, x)` | 꼭 다시 대입해요 |
| `array_merge($a, $b)` | `append(a, b...)`, `slices.Concat(a, b)` |  |
| `in_array($x, $arr, true)` | `slices.Contains(s, x)` |  |
| `array_search($x, $arr)` | `slices.Index(s, x)` | 없으면 `-1` |
| `sort($arr)` | `slices.Sort(s)` | 원본을 정렬해요 |
| `usort($arr, fn($a, $b) => ...)` | `slices.SortFunc(s, func(a, b T) int {...})` | 비교 결과는 음수/0/양수 |
| `array_unique($arr)` | `slices.Sort(s)` 후 `slices.Compact(s)` | 붙어 있는 중복만 지워요 |
| `array_reverse` | `slices.Reverse(s)` | 원본을 뒤집어요 |
| `array_slice($arr, 1, 2)` | `s[1:3]` | 원본 배열을 같이 봐요 ([03편](https://wiki.mailplug.co.kr/confluence/pages/viewpage.action?pageId=224340554)) |
| `array_filter` | for문, 또는 `slices.DeleteFunc` | DeleteFunc는 "지울 것"을 골라요 |
| `array_map` | for문 | 표준 라이브러리에 없어요 |
| `isset($m['k'])` | `v, ok := m["k"]` |  |
| `unset($m['k'])` | `delete(m, "k")` |  |
| `array_keys($m)` | `slices.Collect(maps.Keys(m))` | 순서는 랜덤, 정렬하려면 `slices.Sorted` |

`array_map` 이 없어서 처음엔 답답한데, Go에서는 for문이 제일 읽기 쉽다고 보는 문화예요. 팀에서 공통 함수로 만들기보다 그냥 for문을 쓰는 게 보통이에요.

```go
// PHP: $ids = array_map(fn($u) => $u->id, $users);
ids := make([]int64, 0, len(users))   // 크기를 미리 잡아 두면 append가 빨라요
for _, u := range users {
    ids = append(ids, u.ID)
}
```

`maps.Keys` 는 Go 1.23부터 슬라이스가 아니라 이터레이터(`iter.Seq`)를 돌려줘요. 그래서 슬라이스가 필요하면 `slices.Collect` 나 `slices.Sorted` 로 한 번 감싸야 해요. 옛날 블로그 글의 `maps.Keys` 예제가 컴파일이 안 되면 이 때문이에요.

## 05. JSON — `encoding/json`

```go
type User struct {
    ID    int64  `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email,omitempty"`  // 비어 있으면 필드를 빼요
    pass  string                            // 소문자 필드는 JSON에 안 나가요
}

b, err := json.Marshal(u)                   // json_encode($u)
var u User
err := json.Unmarshal(body, &u)             // json_decode($body)
```

- **struct에 담는 게 기본이에요.** 필드 옆의 `` `json:"..."` `` (태그)로 JSON 키 이름을 정해요. PHP처럼 연관 배열로 받고 싶으면 `map[string]any` 에 담을 수는 있지만, 꺼낼 때마다 타입을 확인해야 해서 잘 안 써요.
- **`map[string]any` 로 받으면 숫자는 다 `float64` 예요.** `{"n":1}` 의 1이 int가 아니라 float64로 들어와요. 큰 ID는 정밀도가 깨질 수 있어요.
- **소문자 필드는 JSON에 안 나가요.** 03편의 "소문자 = 밖에서 못 봄" 규칙이 json 패키지에도 적용돼요. 응답에 필드가 안 나오면 대소문자부터 봐요.
- **빈 슬라이스는 `[]`, nil 슬라이스는 `null` 이에요.** 03편 3장 참고.

## 06. 날짜와 시간 — `time`

Go 날짜 포맷이 제일 낯설어요. `Y-m-d` 같은 기호 대신 **정해진 날짜 하나를 원하는 모양으로 써요.** 그 날짜가 2006년 1월 2일 15시 04분 05초예요. "1월 2일 3시 4분 5초 06년"으로 1, 2, 3, 4, 5, 6 순서라고 외우면 쉬워요.

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `time()` | `time.Now().Unix()` |  |
| `date('Y-m-d H:i:s')` | `time.Now().Format("2006-01-02 15:04:05")` | 상수 `time.DateTime` 도 있어요 |
| `date('Y-m-d')` | `t.Format(time.DateOnly)` |  |
| `strtotime('2026-11-04 10:00:00')` | `time.ParseInLocation(time.DateTime, s, loc)` | 아래 주의 참고 |
| `strtotime('+1 day')` | `t.AddDate(0, 0, 1)` | 시간 단위는 `t.Add(2 * time.Hour)` |
| `sleep(1)` | `time.Sleep(time.Second)` | `time.Sleep(1)` 은 1나노초예요 |
| `microtime(true)` 로 걸린 시간 | `start := time.Now()` … `time.Since(start)` |  |
| `date_default_timezone_set` | `time.LoadLocation("Asia/Seoul")` | 전역 설정이 아니라 값마다 붙어요 |

- **`time.Parse` 는 시간대가 없으면 UTC로 읽어요.** PHP는 `date.timezone` 설정을 따라가지만, Go는 문자열에 시간대가 없으면 UTC예요. 사용자 시간대로 읽으려면 `ParseInLocation` 에 그 사용자의 시간대를 넘겨요. 메일플러그는 해외에서도 접속하니까 서버 시간대를 고정하지 말고, 요청에서 받은 시간대를 써요.
- **`01` 이랑 `02` 를 헷갈리면 조용히 틀려요.** `"2006-01-01"` 로 쓰면 일 자리에 월이 들어가요. 에러가 안 나서 더 위험해요.

## 07. 그 밖에 자주 쓰는 것

| PHP 7.4 | Go | 메모 |
|---|---|---|
| `echo`, `print_r` | `fmt.Println`, `fmt.Printf("%+v", x)` | `%+v` 는 필드 이름까지 찍어요 |
| `var_dump($x)` | `fmt.Printf("%#v", x)` | 타입까지 찍어요 |
| `error_log` | `slog.Error("msg", "key", v)` | 키-값 로그 |
| `throw new Exception('x')` | `return errors.New("x")` | 포맷이 필요하면 `fmt.Errorf` |
| `exit(1)`, `die()` | `os.Exit(1)` | `defer` 가 안 돌아요 |
| `file_get_contents($path)` | `os.ReadFile(path)` | `[]byte` 로 줘요 |
| `file_put_contents` | `os.WriteFile(path, b, 0o644)` | 권한을 꼭 넘겨요 |
| `http_build_query($arr)` | `url.Values{...}.Encode()` | 키가 알파벳 순으로 정렬돼요 |
| `urlencode` / `rawurlencode` | `url.QueryEscape` / `url.PathEscape` | 공백이 `+` / `%20` |
| `htmlspecialchars` | `html.EscapeString` | HTML 만들 땐 `html/template` 이 알아서 해요 |
| `base64_encode` | `base64.StdEncoding.EncodeToString(b)` |  |
| `md5($s)` | `md5.Sum(b)` 후 `hex.EncodeToString(sum[:])` | 두 단계예요 |
| `password_hash` | `bcrypt.GenerateFromPassword` | `golang.org/x/crypto/bcrypt` |
| `uniqid()` | `uuid.NewString()` | `github.com/google/uuid` |

## 08. 스스로 확인해 보기

#### 1. PHP에서 `$limit = intval($_GET['limit'] ?? 50);` 이던 코드를 Go로 옮겼어요. 사용자가 `?limit=abc` 를 보내면 PHP와 Go는 각각 어떻게 될까?

<details>
<summary>답 보기</summary>

PHP는 `intval("abc")` 가 0이라서 limit 0으로 조용히 조회돼요. 빈 목록이 나가고 아무도 몰라요. Go는 `strconv.Atoi("abc")` 가 에러를 주니까 그 에러를 400으로 돌려주면 돼요. gin이면 `ShouldBindQuery` 가 같은 일을 해 줘요.

</details>

#### 2. DB에는 KST로 `"2026-11-04 10:00:00"` 이 저장돼 있어요. `time.Parse(time.DateTime, s)` 로 읽어서 `.Unix()` 를 찍으면 PHP `strtotime` (timezone=Asia/Seoul) 결과랑 같을까?

<details>
<summary>답 보기</summary>

9시간(32400초) 차이가 나요. Go `time.Parse` 는 시간대가 없는 문자열을 UTC로 읽거든요. `time.ParseInLocation` 에 저장할 때 쓴 시간대를 넘겨야 같아져요.

</details>
