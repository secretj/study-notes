# 동기, 비동기 ?

> 작성: 2022-01-04 · 태그: 네트워크 · [노션 원본](https://app.notion.com/p/fca1866506414b59a282c3442325d7eb)

### 비동기(Asynchronous)

: 비동기의 대표적인 예는 AJAX(Asynchronous Javascript XML)

AJAX는 페이지 로딩 시 데이터를 별도로 가져오는 기술이다.

즉, 전체 프레임은 그대로 있고, 내부 데이터만 갱신할 수 있다는 뜻 !

이게 무슨 말이냐 하면 **비동기 방식은 응답 여부와 관계 없이 다시 전송할 수 있다**는 뜻

두 사람이 대화하는데 다른 사람 말 안 끝났는데 말할 수 있음

### 동기

반대로 동기는 응답을 무조건 받아야 요청이 가능한 것이라고 할 수 있겠네요.
