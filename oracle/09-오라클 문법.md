### CASE WHEN THEN END

```sql
SELECT ANIMAL_ID, NAME,
CASE WHEN SEX_UPON_INTAKE LIKE 'Spayed%' THEN 'O'
    WHEN SEX_UPON_INTAKE LIKE 'Neutered%' THEN 'O'
    ELSE 'X'
    END 중성화
FROM ANIMAL_INS
ORDER BY ANIMAL_ID;

//중성화된 건 O로 안된건 X로 컬럼명 중성화로 표기하기 => 조건에 따라 값 변경해서 조회하기
```
