# 부조회(서브쿼리)

### 구절의 순서를 바꿔야 하는 경우

- 예) 최신 등록순으로 정렬한 결과에서 상위 열명을 원하는 경우 ?

SELECT \*

FROM (SELECT \* FROM MEMBER ORDER BY REGDATE DESC)

WHERE ROWNUM BETWEEN 1 AND 10;

⇒ 쿼리에서 소괄호는 수학에서와 같이 먼저 실행하겠습니다. 라는 뜻

**즉, 서브쿼리는 먼저 실행해야 하는 경우가 있으면 사용한다 !**

예) 나이가 30 이상인 회원 목록을 조회하시오.

SELECT \*

FROM MEMBER

WHERE AGE≥30;

예) 나이가 평균나이 이상인 회원 목록을 조회하시오.

SELECT \*

FROM MEMBER

WHERE AGE≥ (SELECT AVG(AGE) FROM MEMBER)
