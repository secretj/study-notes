# C언어의 기본 문법

- C는 **절차적 언어** <br>: C로 작성한 코드는 **데이터보다 프로세스에 중점**이 맞춰져 있다.(순서대로 코드진행한다⇒ 컴퓨터 구조의 모습)
- class없다
- **함수는 모두 전역 함수다(어디서나 호출 가능하다)**
- **변수는 함수밖에 선언되면 전역변수<br>함수 안에 선언되어있으면 지역변수**
