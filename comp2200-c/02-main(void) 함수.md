# main(void) 함수

- **프로그램의 진입점**
- 반드시  int를 반환해야함 =⇒ **return 0;은 프로그램에 문제가 없다**는 뜻

![](images/9e8ea078-786f-4df2-a108-96c7c0173dc0.png)

- main(void)에서 **void를 생략하면 매개변수를 받겠다는 뜻**(매개변수의 갯수와 자료형을 모른다.) <br>그래서 **매개변수를 안 받을거면 void를 꼭 넣어줘야한다.**
