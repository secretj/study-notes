# 변수 선언

### 변수 선언 위치

- 변수 선언은 반드시 블럭의 시작에서만 해야 한다.
- **컴파일 오류**

```c
int main(void)
{
	 int num1 =10;
	 int num2= 1234;

	 printf("num1=%d, num2 = %d", num1, num2);

	 int result = add(num1, num2); /* 컴파일 오류 발생*/
	 printf("%d+ %d = %d", num1, num2, result);

	result 0;
}
```

- **컴파일**

```c
int main(void)
{
	 int num1 =10;
	 int num2= 1234;
	 int result;

	 printf("num1=%d, num2 = %d", num1, num2);

	 result = add(num1, num2); /* 컴파일*/

	printf("%d+ %d = %d", num1, num2, result);

	result 0;
}
```
