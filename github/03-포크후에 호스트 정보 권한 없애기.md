# 포크후에 호스트 정보 권한 없애기

**fork를 하고 나면 그 포크당한 사람의 호스트 정보가 남아있게 된다.**

그래서 그 정보를 제거해줘야 내 레포지토리가 되는데

1. gitbash에서 fork받은 로컬 주소로 이동
2. **rm -rf .git**   ⇒ 호스트 정보 제거

: 이렇게 하고 나면 디렉토리에 설정이 모두 날아가기 때문에

3. **git init**  ⇒ 을 통해 디렉토리에 깃설정을 등록해주고
4. **git remote add origin URL**   ⇒으로 본인의 git 레포지토리 주소를 등록해준다.
