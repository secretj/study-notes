# 인터페이스와 추상클래스 차이

### class는 상태와 행위가 존재함.

- 인터페이스는 행위(메서드)를 공유하는 것이고, 추상클래스는 상태(변수)를 공유하기 위해 사용함.

### extends는 확장 class에서 class를 상속받을 때(interface에서 interface), implements는 상속 class에서 interface를 상속받을 때
