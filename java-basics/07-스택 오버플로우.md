# 스택 오버플로우

> 작성: 2022-01-18 · 태그: JAVA · [노션 원본](https://app.notion.com/p/7b2084c5179a4074ac61769917951039)

Stack Overflow는 Stack영역의 메모리가 지정한 범위를 넘어갈 때 발생한다.

Stack메모리는 보통 지역 변수가 저장되는 영역이다.

**함수에서 지역 변수를 선언하면 지역 변수는 스택에 저장**되고,

**함수를 빠져나오면 지역 변수는 스택 메모리에서 해제**된다.

### 오버플로우 발생 원인

: 만약 **한 함수에서 너무 큰 지역 변수를 선언**하거나, **재귀적으로 무한정 호출**하게 되면 스택 **오버플로우가 발생**한다.

### 해결방법

- 컴파일러 옵션에서 스택 메모리의 크기를 늘린다.
- 함수에서 사용하는 지역 변수의 크기를 줄인다.
- 지역 변수를 전역 변수로 바꾸어 사용한다.

JAVA에서 스택 메모리는 JVM이 할당해준다.
